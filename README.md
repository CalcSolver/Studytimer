# StudyFocus Timer

A simple, clean study timer designed to help students stay focused during revision sessions.  
Enter a time, start the countdown, and keep track of your study intervals with a distraction‑free interface.

## Features
- Minimal, study‑friendly design  
- Custom time input (MM:SS)  
- Start/stop/reset controls  
- Works on school iPads and browsers  
- No external dependencies  

## Special Functions
The timer includes an optional “advanced mode” that activates when a specific time value is entered.  
This is designed for testing extended UI components and iframe layouts inside the page.

## Why This Exists
StudyFocus Timer was created as a lightweight productivity tool for students who want a simple way to manage revision blocks without installing apps or extensions.
